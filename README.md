# Leon Creative Agency Template

A polished one-page agency landing page built with HTML and CSS, inspired by the classic Leon design aesthetic but refreshed for modern browsing and responsive layouts.

## Overview

This project is a static marketing website for a creative studio or agency. It includes a hero section, services, portfolio, about, and contact sections with a clean, minimal, and professional look.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern hero section with clear CTA buttons
- Service cards and portfolio gallery
- Clean typography and consistent spacing
- Attractive hover states and refined color system
- Accessible navigation and contact links

## Project Structure

- `index.html` — main page content
- `CSS/leon.css` — custom styling and responsive rules
- `CSS/normalize.css` — browser reset
- `CSS/all.min.css` — Font Awesome icons
- `Images/` — project assets and media files

## Run Locally

Because this is a static site, you can preview it in two easy ways:

1. Open `index.html` directly in a browser.
2. Or serve the folder locally:

   python -m http.server 8000

Then open:

http://localhost:8000

## Customization

You can edit the content directly in `index.html` and adjust the look in `CSS/leon.css` to match your brand colors, content, or style preferences.
